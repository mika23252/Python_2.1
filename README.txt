Описание функций:

Добавление новой задачи с автоинкрементным ID, вводом названия и приоритета (1–5), статус по умолчанию “не выполнено”.

Вывод списка всех задач в формате [ID] Название | Приоритет | Статус.

Удаление задачи по её ID.

Смена статуса задачи (выполнено/не выполнено).

Фильтрация задач по статусу: показывать только выполненные или только невыполненные.

Сортировка задач по приоритету (по убыванию).

------------------------------------------------------------------------------------------------------------------------

Инструкции по запуску:

Убедитесь, что установлен Python 3.6 или выше.

Сохраните файл task_manager.py в удобную папку.

В терминале перейдите в эту папку.

Запустите команду:
python task_manager.py
